MISTRIA TOGETHER - co-op for Fields of Mistria
==============================================

Everyone who plays does this once:

  1. Install MOMI (Mods of Mistria Installer) if you have not yet:
     https://github.com/Garethp/Mods-of-Mistria-Installer/releases

  2. Run the installer in this folder:
        Windows:  double-click  Install.bat
        Linux / macOS:  ./install.sh
     It puts a small helper in the background (no window; it starts by
     itself from now on) and copies the extracted mt folder into your MOMI
     mods folder. MOMI needs manifest.toml directly inside that folder;
     it cannot install the convenience ZIP by itself.

  3. Open MOMI and press Install. Remove any other multiplayer mod first.

Then, in the game:

  * Title screen: the Multiplayer button (top right), or
    while playing: press F9.
  * One player picks Host. Everyone else picks Join.
    On the same network the host is found automatically.
    Over the internet (or Tailscale), type the host's address once;
    it is remembered.
  * Load a save. That is all.

To remove it again:  mistria-together uninstall

More: https://github.com/RobertFrank06/mistria-together
